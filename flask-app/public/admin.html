Codes

New codes belong to the selected folder. Responses submitted with a code go into that code’s folder.

New codes start with 30 responses. Add additional responses to an individual code below, or create another code. Everyone uses the same employee-form link.

Folder submission limit

This folder can receive up to the saved submission limit across all its codes combined. New folders default to 100 submissions. Each code has its own response allowance, starting at 30. Adding responses to a code does not increase the folder’s total submission limit.

Repeat submissions and corrections count toward both limits. Rejecting or deleting a response does not restore the allowance. The folder limit does not reset weekly or monthly.
